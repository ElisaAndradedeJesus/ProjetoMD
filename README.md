# ProjetoMD

Projeto em grupo para apresentar na feira de ciência e tecnologia.
A ideia inicial é criar um jogo Genius e estudar quanto tempo e memória
os algoritmos usam. Ainda vamos escolher as tecnologias e o que será feito.

## Quero ajudar. Por onde começo?

Leia o [passo a passo para participar](CONTRIBUTING.md).
Ele explica como enviar suas mudanças para outra pessoa conferir antes de
elas entrarem na versão principal do projeto.

**A regra principal é: ninguém muda a versão principal sozinho.**

Quem administra o repositório também precisa seguir o
[passo a passo para ativar a proteção](docs/protecao-github.md).
A proteção só funciona depois dessa configuração no GitHub.
